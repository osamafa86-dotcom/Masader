# خطة بناء منصة "مرصد الدراسات الاستراتيجية" (رصد ← ترجمة ← نشر بالعربية)

**التاريخ:** 20 تشرين الثاني 2026
**الجمهور:** فريق التطوير وصاحب المشروع
**الحالة:** مسودة أولى للاعتماد. القرارات المعلّمة بـ «قراري» افتراضات قابلة للتعديل.

---

## 0. الخلاصة التنفيذية (ما تحتاج معرفته في دقيقة)

1. **المشروع ليس "موقع ترجمة"، بل محرك رصد تحريري** له ثلاث طبقات: راصد يلتقط الجديد من المصادر، خط معالجة وترجمة بالذكاء الاصطناعي مع مراجعة بشرية، وموقع نشر بحثي بالعربية مع بحث وأرشيف وتنبيهات.
2. **أكبر خطر ليس تقنياً بل حقوقياً.** معظم المصادر الـ19 محمية بحقوق النشر (RAND، CSIS، War on the Rocks، مجلات Taylor & Francis، Janes). ترجمة المقال كاملاً ونشره بلا إذن = انتهاك. الخطة تبني المنتج على ثلاثة مستويات نشر (كامل / مطوّل / ملخص+رابط) تُحدَّد لكل مصدر حسب رخصته. هذا يحمي المشروع ويجعله أكثر قيمة للباحث لا أقل.
3. **اللغة والتقنية (قراري):** Python لخط الرصد والمعالجة والترجمة (أقوى منظومة لاستخراج النصوص والتعامل مع PDF وRSS)، وTypeScript/Next.js للموقع (أفضل دعم لواجهات RTL عالية الجودة وSEO)، وPostgreSQL قاعدة بيانات واحدة لكل شيء. التفاصيل والبدائل في القسم 4.
4. **نموذج الترجمة:** نماذج Claude عبر الواجهة البرمجية مع مسرد مصطلحات إلزامي ومراجعة بشرية قبل النشر. التكلفة التقديرية لترجمة مقال من 2000 كلمة تتراوح بين 7 و15 سنتاً أمريكياً، أي أن 50 مادة يومياً تكلّف نحو 100 إلى 220 دولاراً شهرياً.
5. **المدة:** نسخة أولى قابلة للاستخدام (MVP) خلال 8 أسابيع بفريق من 2 إلى 3 أشخاص، ثم نسختان لاحقتان خلال 4 أشهر.

## 1. تعريف المنتج

### 1.1 الهدف
منصة عربية تتابع يومياً أهم مراكز الفكر والمجلات الأكاديمية في الدراسات الأمنية والاستراتيجية والاستخباراتية والتاريخ العسكري، وتقدّم محتواها للقارئ العربي المتخصص بصيغة موثوقة ومنظّمة وقابلة للبحث والاستشهاد.

### 1.2 الجمهور
- باحثون وطلاب دراسات عليا في العلاقات الدولية والدراسات الأمنية.
- محللون في مراكز أبحاث ومؤسسات حكومية وإعلامية.
- صحفيون متخصصون وقراء مهتمون.

### 1.3 ما الذي يجعل المنصة ذات قيمة (وليست مجرد ترجمة آلية)
| العنصر | لماذا يهم الباحث |
|---|---|
| **ملخص تحليلي عربي** لكل مادة (300 إلى 600 كلمة) بصيغة: الأطروحة، الأدلة، التوصيات، نقاط الخلاف | يوفّر وقت القراءة ويعطي قيمة حتى للمصادر المدفوعة التي لا يمكن نشرها كاملة |
| **بطاقة تعريفية موحّدة**: المؤلف، المؤسسة، التاريخ، النوع (تقرير/مقال/دراسة محكّمة)، المنطقة، الموضوع، الرابط الأصلي، صيغة الاستشهاد | يحوّل الموقع إلى قاعدة بيانات بحثية وليس مجرد مدوّنة |
| **مسرد مصطلحات ثنائي اللغة** يتراكم مع الوقت ويُطبَّق على كل الترجمات | يحل مشكلة فوضى المصطلح العربي في هذا الحقل (مثل deterrence، gray zone، A2/AD) |
| **عرض ثنائي اللغة** (الفقرة الأصلية بجوار الترجمة) حيث تسمح الرخصة | يبني الثقة ويسمح للباحث بالتحقق |
| **بحث عربي متقدم** بالموضوع والمنطقة والمؤسسة والفترة الزمنية والمؤلف | الأرشيف هو الأصل الحقيقي للمنصة بعد سنة |
| **تنبيهات ونشرات** (بريد أسبوعي، RSS عربي، تنبيه بكلمات مفتاحية) | يحوّل الزائر إلى مستخدم دائم |
| **شفافية الترجمة**: شارة "ترجمة آلية مُراجَعة بشرياً" أو "ترجمة آلية" مع تاريخ المراجعة واسم المراجع | ضرورة أخلاقية ومهنية في محتوى بحثي |

### 1.4 ما لن نبنيه في البداية (حدود واضحة)
- لا منتدى ولا تعليقات في النسخة الأولى.
- لا تطبيق جوّال؛ الموقع متجاوب يكفي.
- لا ترجمة فورية عند الطلب لأي رابط يدخله المستخدم (مشكلة حقوقية وتكلفة غير محدودة).
- لا نشر لنص كامل من مصدر لم نتأكد من رخصته.

### 2.1 القاعدة التحريرية للحقوق (ثلاثة مستويات)
- **المستوى أ، نشر كامل:** رخصة مفتوحة (CC BY / CC BY-NC) أو ملك عام أو اتفاق شراكة مكتوب. تُنشر الترجمة الكاملة + العرض ثنائي اللغة + الإسناد الكامل وذكر الرخصة.
- **المستوى ب، نشر مطوّل:** إذن عام من المصدر على ترجمة بشروط (مثل عدم التعديل، الإشارة للمصدر). تُنشر الترجمة الكاملة أو مقتطفات واسعة حسب الإذن.
- **المستوى ج، ملخص تحليلي + رابط:** الافتراضي لكل مصدر محمي. ملخص عربي بصياغتنا (300 إلى 600 كلمة)، اقتباسات قصيرة مترجمة لا تتجاوز حدوداً معقولة (قراري: 150 كلمة مجتمعة)، بيانات الاستشهاد، ورابط للأصل. **هذا ليس تنازلاً**: الملخص التحليلي الجيد هو ما يبحث عنه القارئ المتخصص المشغول.

تُسجَّل الرخصة والإذن ودليلهما (رابط صفحة الشروط، نسخة من البريد) في حقل `rights` لكل مصدر، ويرفض النظام تلقائياً نشر مادة بمستوى أعلى مما تسمح به رخصة مصدرها.

### 2.2 قواعد الزحف المحترم (لحماية المشروع من الحظر والمساءلة)
- احترام `robots.txt` وقراءة شروط الاستخدام لكل موقع.
- تفضيل RSS/Atom على الزحف؛ لا زحف إلا للمصادر بلا خلاصة (13، 18، 19).
- معرّف User-Agent واضح يذكر اسم المنصة وبريداً للتواصل.
- معدل طلبات منخفض (طلب واحد كل عدة ثوانٍ لكل نطاق)، مع احترام ETag وLast-Modified.
- عدم تجاوز أي حاجز دفع أو تسجيل دخول إطلاقاً.

## 3. المعمارية العامة

```
المصادر (RSS / HTML / PDF)
        │
        ▼
┌───────────────────┐    ┌───────────────────┐    ┌───────────────────┐
│ 1. الراصد          │───▶│ 2. المستخرج        │───▶│ 3. المُطبِّع         │
│ fetcher           │    │ extractor         │    │ normalizer/dedup  │
│ RSS + زحف مجدول    │    │ HTML→نص، PDF→نص    │    │ تنظيف، لغة، تكرار  │
└───────────────────┘    └───────────────────┘    └─────────┬─────────┘
                                                          ▼
┌───────────────────┐    ┌───────────────────┐    ┌───────────────────┐
│ 6. النشر والموقع   │◀───│ 5. المراجعة البشرية │◀───│ 4. خط الذكاء الاصطناعي│
│ Next.js (RTL)     │    │ لوحة تحرير        │    │ تصنيف، ملخص، ترجمة  │
│ بحث، أرشيف، RSS   │    │ موافقة/تعديل/رفض   │    │ مسرد، فحص جودة     │
└───────────────────┘    └───────────────────┘    └───────────────────┘
        │
        ▼
  7. التنبيهات والنشرة البريدية + واجهة برمجية عامة (API)
```

**البنية التحتية المشتركة:** PostgreSQL (البيانات + البحث النصي + المتجهات عبر pgvector)، Redis (صفوف المهام والتخزين المؤقت)، تخزين كائنات متوافق مع S3 (ملفات PDF الأصلية، لقطات HTML للأدلة)، مراقبة وسجلات.

### 3.1 المكوّنات تفصيلاً

**1. الراصد (Fetcher)**
- جدول `sources` يحوي لكل مصدر: نوع الالتقاط (rss / sitemap / html_list)، الرابط، التكرار (كل 30 دقيقة للمصادر اليومية، كل 6 ساعات للمجلات)، قواعد الاختيار (CSS selectors) للمصادر المزحوفة، وحالة الصحة.
- مهام مجدولة (Celery beat أو APScheduler) تضع مهمة التقاط لكل مصدر في الصف.
- التعامل مع المواقع كثيفة JavaScript عبر Playwright عند الحاجة فقط (قراري: ISW مرشّح لذلك).
- كل عنصر جديد يُخزَّن أولاً كـ `raw_item` (الرابط، العنوان، تاريخ النشر الأصلي، HTML الخام أو PDF) قبل أي معالجة، لضمان إمكانية إعادة المعالجة لاحقاً.

**2. المستخرج (Extractor)**
- HTML: مكتبة `trafilatura` (الأدق حالياً في استخراج نص المقال وإزالة القوائم والإعلانات) مع بديل `readability-lxml`.
- PDF: `pymupdf` للنص، مع كشف الأعمدة والحواشي؛ `marker` أو خدمة OCR للملفات المصوّرة (RAND وStudies in Intelligence وParameters).
- استخلاص البيانات الوصفية: المؤلفون، التاريخ، النوع، الكلمات المفتاحية من `<meta>` وSchema.org وJSON-LD، مع تكملة بالنموذج اللغوي عند النقص.

**3. المُطبِّع وكاشف التكرار (Normalizer/Dedup)**
- تطبيع الرابط (إزالة معاملات التتبع) + بصمة محتوى (SimHash) لكشف إعادة النشر بين المصادر (مقال يظهر في WOTR وSWJ معاً).
- كشف اللغة (معظمها إنجليزي، مع جاهزية لمصادر فرنسية وروسية وغيرها لاحقاً).
- حساب عدد الكلمات وتقدير وقت القراءة والتكلفة قبل إرسال المادة للترجمة.

**4. خط الذكاء الاصطناعي (الجزء الأهم، تفصيله في القسم 5)**
- التصنيف: الموضوعات (الردع، الاستخبارات، الحرب السيبرانية، الصين، روسيا، الشرق الأوسط…)، المنطقة، النوع، الأهمية التحريرية (1 إلى 5).
- الملخص التحليلي العربي.
- الترجمة الكاملة (فقط للمستويين أ وب).
- فحص الجودة الآلي.

**5. المراجعة البشرية (لوحة التحرير)**
- صف مراجعة بالأولوية؛ عرض ثنائي اللغة قابل للتعديل فقرة بفقرة؛ تمييز المصطلحات المأخوذة من المسرد؛ أزرار: اعتماد / تعديل / إعادة ترجمة فقرة / رفض.
- إمكانية إضافة مصطلح للمسرد من داخل المراجعة بنقرة واحدة.
- سجل تدقيق كامل (من راجع، ماذا غيّر، متى).

**6. النشر والموقع**
- Next.js (App Router) مع عرض خادمي (SSR) وتخزين ثابت متزايد (ISR) لسرعة عالية وSEO عربي ممتاز.
- صفحات: الرئيسية (الأحدث + الأهم)، صفحة المادة، صفحة المصدر، صفحة الموضوع، صفحة المؤلف، البحث، المسرد، "عن المنصة ومنهجية الترجمة".
- RTL كامل مع خطوط عربية مناسبة للقراءة الطويلة (قراري: IBM Plex Sans Arabic للواجهة وNoto Naskh Arabic للنصوص الطويلة) وضبط دقيق لعرض الأرقام والمصطلحات اللاتينية داخل النص العربي (`unicode-bidi: isolate`).

**7. التنبيهات والواجهة البرمجية**
- RSS/Atom عربي لكل موضوع ومصدر.
- نشرة بريدية أسبوعية مولَّدة تلقائياً (أهم 10 مواد) تُراجَع قبل الإرسال.
- واجهة برمجية عامة للقراءة (REST + JSON) مع مفاتيح للمؤسسات البحثية (مرحلة لاحقة).

| **ج. Django الكامل (Python فقط)** | Django + Django Admin للتحرير + قوالب خادمية للموقع | لغة واحدة؛ لوحة تحرير شبه مجانية من Django Admin | واجهة الموقع العام ولوحة المراجعة ثنائية اللغة التفاعلية ستكون أضعف؛ تجربة المستخدم الحديثة أصعب بلا React |

**قراري: المقاربة أ.** السبب الحاسم: جودة الاستخراج هي أساس جودة الترجمة، وPython تتفوق فيها بلا منازع، بينما الموقع العربي البحثي يحتاج واجهة من الطراز الأول وNext.js الأنسب لها. إن كان الفريق شخصاً واحداً فقط في البداية، فالمقاربة ج هي البديل المقبول، مع الانتقال إلى أ لاحقاً.

## 5. خط الترجمة بالذكاء الاصطناعي (قلب المشروع)

### 5.1 مبادئ
1. **المسرد أولاً:** لا تُرسَل أي مادة للترجمة قبل إرفاق المصطلحات ذات الصلة من المسرد في موجه النظام. المسرد يُبنى في المرحلة 0 (نواة 300 إلى 500 مصطلح) ويتراكم من المراجعين.
2. **الترجمة بالفقرات المرقّمة لا بالنص المفتوح:** النص يُقسَّم إلى فقرات مرقّمة وتُطلب الترجمة بمخرجات منظّمة (Structured Outputs) تربط كل ترجمة برقم فقرتها. هذا يمنع الحذف والدمج ويُمكّن العرض ثنائي اللغة.
3. **السياق الكامل:** تُرسَل المادة كاملة مع العنوان والملخص والبيانات الوصفية، لأن الترجمة الفقرة بفقرة بمعزل عن السياق تفسد الاتساق.
4. **لا نشر بلا مراجعة بشرية** للمواد ذات الأهمية 3 فما فوق؛ المواد الأقل أهمية تُنشر بشارة "ترجمة آلية" مع إمكانية الإبلاغ عن خطأ.
5. **شفافية:** كل مادة تحمل: نموذج الترجمة، تاريخها، حالة المراجعة، اسم المراجع (أو الفريق).

### 5.2 اختيار النماذج (أسعار الواجهة البرمجية الحالية لكل مليون رمز: إدخال/إخراج)
| المهمة | النموذج | السبب |
|---|---|---|
| الترجمة الكاملة والملخص التحليلي | `claude-opus-5-5` (4$ / 20$) | أعلى جودة في العربية الأكاديمية والالتزام بالمسرد؛ الفرق في التكلفة مقابل النموذج الأوسط صغير مقارنة بتكلفة المراجعة البشرية |
| التصنيف واستخلاص البيانات الوصفية وكشف التكرار الدلالي | `claude-haiku-5-5` (0.10$ / 0.50$) | مهام قصيرة عالية الحجم |
| فحص الجودة الآلي (قاضٍ مستقل) | `claude-sonnet-5-5` (2$ / 10$) | مراجعة الترجمة مقابل الأصل وإخراج قائمة مشكلات محددة |

- تُنفَّذ الترجمات غير العاجلة عبر **Message Batches** بخصم 50% (المجلات الأكاديمية والأرشيف).
- يُستخدم **Prompt Caching** لموجه النظام والمسرد (ثابتان) لتقليل تكلفة الإدخال.
- تُفعَّل آلية الـ fallbacks الخادمية للتعامل مع حالات الرفض النادرة.

### 5.3 تقدير التكلفة لكل مادة (2000 كلمة إنجليزية)
- إدخال: نحو 2700 رمز للنص + 1500 رمز للموجه والمسرد (مع التخزين المؤقت يصبح أرخص بكثير).
- إخراج عربي: نحو 5000 إلى 6000 رمز (العربية تستهلك رموزاً أكثر من الإنجليزية).
- Opus 5.5: ≈ 0.14$ للمادة؛ بالدُفعات ≈ 0.07$.
- إضافة الملخص والتصنيف والفحص: ≈ +0.05$.
- **50 مادة يومياً ≈ 100 إلى 220$ شهرياً.** التكلفة الحقيقية هي وقت المراجع البشري، لا الواجهة البرمجية.

### 5.4 موجه النظام للترجمة (الهيكل)
- الدور: مترجم متخصص في الدراسات الاستراتيجية والأمنية إلى العربية الفصحى المعاصرة بأسلوب مراكز الأبحاث العربية الرصينة.
- القواعد: الالتزام الحرفي بالمسرد المرفق؛ إبقاء الاسم الأصلي للمصطلح بين قوسين عند أول ظهور للمصطلحات التقنية والأسماء؛ عدم إضافة أو حذف أي معلومة؛ الحفاظ على الحواشي والأرقام والتواريخ والوحدات؛ تحويل الاختصارات مع شرحها أول مرة؛ أسماء الأعلام والمؤسسات بالصيغة العربية المستقرة إن وُجدت وإلا بالنقل الصوتي مع الأصل.
- المخرجات: JSON منظّم: `[{id, ar, notes?}]` حيث `notes` لأي التباس يحتاج قرار المراجع.

### 5.5 ضبط الجودة
- **مجموعة اختبار ذهبية:** 30 مقالاً متنوعاً تُترجم وتُراجع بشرياً مرة واحدة بعناية؛ كل تغيير في الموجه أو النموذج يُقاس عليها قبل الاعتماد.
- **قاضٍ آلي** يفحص: الحذف، الإضافة، أخطاء الأرقام والتواريخ، مخالفة المسرد، التراكيب المترجمة حرفياً. يُخرج قائمة مشكلات بمواقعها لا درجة فقط.
- **عيّنات دورية:** 10% من المواد المنشورة بشارة "آلية" تُراجَع أسبوعياً، وتُسجَّل أنواع الأخطاء لتحسين الموجه والمسرد.
- **زر "أبلغ عن خطأ في الترجمة"** في كل فقرة على الموقع.

## 7. الموقع العام: المتطلبات التفصيلية

- **صفحة المادة:** العنوان العربي + الأصلي، بطاقة التعريف، الملخص التحليلي، النص (حسب المستوى)، مفتاح "عرض الأصل بجوار الترجمة" (إن سُمح)، مصطلحات المادة من المسرد مع تعريفاتها، مواد ذات صلة (بحث دلالي)، أزرار الاستشهاد (APA، Chicago، BibTeX)، رابط الأصل بارز.
- **البحث:** تطبيع عربي قبل الفهرسة (توحيد الهمزات أ/إ/آ ← ا، التاء المربوطة/الهاء، الياء/الألف المقصورة، حذف التشكيل)، مرشّحات بالمصدر والموضوع والمنطقة والتاريخ والنوع ومستوى النشر، وبحث دلالي اختياري "ابحث بالمعنى".
- **المسرد كصفحة مستقلة** قابلة للبحث والتصفح، كل مصطلح يربط بالمواد التي ورد فيها. هذه الصفحة وحدها قد تصبح مرجعاً مستقلاً.
- **الأداء وSEO:** توليد ثابت للصفحات، بيانات Schema.org (ScholarlyArticle/NewsArticle مع `translationOfWork`)، خريطة موقع، Open Graph بالعربية، Core Web Vitals ممتازة.
- **إمكانية الوصول:** تباين كافٍ، تنقل بلوحة المفاتيح، أحجام خط قابلة للتكبير، وضع ليلي.
- **صفحة المنهجية:** تشرح بوضوح سياسة الحقوق ومستويات النشر وآلية الترجمة والمراجعة. هذه الصفحة ضرورية للمصداقية وللعلاقة مع المصادر.
