# Marsad Phase 1 (MVP) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A working monitor → extract → AI translate → human review → Arabic publish pipeline for 8 sources, with a public RTL site and an editor dashboard.

**Architecture:** Python engine (`engine/`): FastAPI API + a single worker process that schedules fetches and advances documents through a DB-backed stage machine (Postgres `FOR UPDATE SKIP LOCKED` instead of Redis/Celery for the MVP). Next.js site (`web/`) renders public pages server-side from the engine API and hosts the editor UI. Postgres is the only stateful service.

**Tech Stack:** Python 3.13, FastAPI, SQLAlchemy 2, Alembic, psycopg 3, httpx, feedparser, trafilatura, pymupdf, anthropic SDK 2.x; Next.js 15 App Router, TypeScript, Tailwind 4, self-hosted Arabic fonts (@fontsource).

**Spec:** `docs/strategy-plan-ar.md` (sections 2, 3, 5, 6, 7, 8 "المرحلة 1").

## Global Constraints

- Rights levels per source: `a` (open licence / public domain / agreement) and `b` (written permission) → max publish level `full`; `c` → `summary` only. Default for any source without evidence: `c`.
- Level-`c` documents are never sent for full translation, and the public API never returns body text for them.
- Quotes in a summary: at most 3, at most 150 English words combined.
- If `SITE_COMMERCIAL=true`, any source whose licence contains `NC` is treated as level `c`.
- Sources with `per_item_copyright_check: true` (Parameters, MWI, Studies in Intelligence) downgrade an item to `summary` when its text carries a `©` notice.
- Items with importance ≥ `REVIEW_MIN_IMPORTANCE` (default 3) or any QA issue of severity `high` require human approval; others may auto-publish with a "machine translation" badge when `AUTO_PUBLISH=true` (default false until the editor decides).
- Models: translation & summary `claude-opus-5-5`; classification `claude-haiku-5-5`; QA judge `claude-sonnet-5-5`. Fallbacks `"default"` with beta `server-side-fallback-2026-07-01` on Opus/Sonnet calls.
- Daily AI budget cap `DAILY_BUDGET_USD` (default 15); AI stages pause when today's spend reaches it.
- HTTP: User-Agent `MarsadBot/0.1 (+contact)`, ≥ 5 s between requests to the same host, honour robots.txt, ETag/Last-Modified.
- All user-facing copy in Arabic; HTML `lang="ar" dir="rtl"`; Latin fragments wrapped in `<bdi>`/`dir="ltr"`.

## Review Focus

1. A feed lists the same article with tracking params (`?utm_source=…`) or a trailing slash → stored once.
2. The model drops, merges or renumbers paragraphs → detected by id check, missing ids retried once, item flagged, never auto-published.
3. A level-`c` document whose DB row somehow holds body text → public API still returns no body.
4. Arabic search with hamza / ta-marbuta / alif-maqsura variants (أ/ا، ة/ه، ى/ي) and diacritics → finds the article.
5. One source times out or returns 500 → its `last_error` recorded, other sources still fetched, worker keeps running.
