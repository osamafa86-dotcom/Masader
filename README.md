# مرصد: الدراسات الاستراتيجية بالعربية

منصة ترصد مراكز الفكر والمجلات المحكّمة في الدراسات الاستراتيجية والأمنية، وتعدّ لكل مادة ملخصاً تحليلياً عربياً،
وتترجم النص كاملاً حين تسمح حقوق المصدر، ثم ينشرها محرر بعد المراجعة.

يضم المستودع **المراحل الثلاث** من الخطة في `docs/strategy-plan-ar.md`.
خطط التنفيذ التفصيلية في `docs/superpowers/plans/`.

## ما الذي يعمل الآن

| الجزء | الوصف |
|---|---|
| الرصد | خلاصات RSS وصفحات القوائم، مع احترام robots.txt وفاصل 5 ثوانٍ لكل نطاق وطلبات شرطية (ETag) |
| الاستخراج | نص المقالات من HTML وملفات PDF، مع حذف القوائم والترويسات المكررة، وكشف المواد المكررة بين المصادر |
| الحقوق | ثلاثة مستويات لكل مصدر، ولا يُترجم النص الكامل لمصدر محمي ولا يخرج من الواجهة البرمجية أبداً |
| الذكاء الاصطناعي | تصنيف (Haiku 5.5)، ملخص تحليلي وترجمة بالفقرات المرقّمة (Opus 5.5)، فحص جودة آلي، سقف إنفاق يومي |
| التحرير | صف مراجعة، تعديل الملخص والفقرات، اقتراح ترجمة بديلة لفقرة، نشر ورفض وإزالة فورية، مسرد، بلاغات القرّاء |
| الموقع العام | عربي من اليمين لليسار، عرض الأصل بجوار الترجمة، بحث عربي يتجاهل الهمزات والتشكيل وأداة التعريف، مسرد، RSS |
| التشغيل | Docker Compose مع HTTPS تلقائي ونسخ احتياطي يومي، وتكامل مستمر على GitHub Actions |
| المجلات المحكّمة | ملخص عربي من الملخص المنشور فقط دون تنزيل المقال المدفوع، وفهرس مترجم لكل عدد، وترخيص خاص بالمادة لمقالات الوصول المفتوح |
| التقارير الطويلة | تتبّع ملف PDF من صفحة التقرير، وقراءة الصفحات ذات العمودين بالترتيب الصحيح، وحذف الحواشي والترويسات |
| الاستيراد اليدوي | يلصق المحرر رابط صفحة أو PDF لمادة لا تصل آلياً، مثل أعداد «دراسات في الاستخبارات» |
| البحث بالمعنى | متجهات pgvector مع دمج نتائج البحث بالكلمات، ومواد ذات صلة، مع رجوع تلقائي إلى البحث بالكلمات عند غياب المتجهات |
| الكتّاب والاستشهاد | صفحة لكل كاتب، واستشهاد بصيغ APA وشيكاغو وBibTeX، واستشهاد بالترجمة العربية نفسها |
| النشرة البريدية | اشتراك بتأكيد مزدوج، وتنبيهات بالموضوع والمصدر والكلمة المفتاحية، ومسودة أسبوعية لا تُرسل إلا بموافقة المحرر، وإلغاء اشتراك بنقرة واحدة |
| المسرد | ترتيب المصطلحات المقترحة بعدد مرات اقتراحها، مع مادة مثال لكل مصطلح |
| الواجهة البرمجية للمؤسسات | `/v1` بمفاتيح تُخزَّن مشفّرة بالتجزئة وحد للطلبات في الدقيقة، وتوثيق تفاعلي في `/v1/docs`، وقواعد الحقوق نفسها |
| الملفات الموضوعية | ملف يجمع مواد قضية واحدة مع ملاحظة على كل مادة، واقتراح مواد، ومقدمة يقترحها النموذج ولا تُنشر قبل مراجعة المحرر |
| الاتجاهات الشهرية | إحصاءات بحسب الموضوع والمنطقة والمصدر مع مقارنة بالأشهر السابقة، وقراءة شهرية يكتب النموذج مسودتها من الأرقام فقط |
| اللغات | ترجمة مباشرة من الفرنسية والروسية والعبرية والصينية دون المرور بالإنجليزية، ومسرد لكل لغة، وتلخيص المصادر العربية دون ترجمة |
| حسابات القرّاء | دخول برابط بريدي لمرة واحدة، ومكتبة محفوظات مع ملاحظات، وتنبيهات، وحذف الحساب وكل بياناته بخطوة واحدة |

المصادر النشطة الآن 16 مصدراً. لم تُفعَّل مجلة التاريخ العسكري حتى تُضبط طريقة قراءة صفحتها،
ولا «دراسات في الاستخبارات» لأنها بلا خلاصة وتُضاف أعدادها بالاستيراد اليدوي، ولا Janes لأنها خدمة تجارية مغلقة.

## قبل الإطلاق (المرحلة 0 في الخطة)

1. **تحقق من روابط الخلاصات** من جهاز متصل بالإنترنت. بيئة البناء لم تصل إلى مواقع المصادر،
   فالروابط في `engine/marsad/data/sources.yaml` غير مؤكدة، وأقلها يقيناً روابط CSIS وRAND وLawfare وصفحة ISW:

   ```bash
   marsad sources check
   ```

   ثم صحّح أي رابط فاشل من لوحة التحرير أو من ملف المصادر.
2. **راسل المصادر** لطلب إذن الترجمة (نموذج الرسالة في الملحق أ من الخطة). عند وصول إذن، يرفع المدير مستوى المصدر
   إلى `b` ويوثق الدليل؛ النظام يرفض تغيير المستوى دون دليل.
3. **راجع المسرد الأولي** (128 مصطلحاً) مع خبير، فهو نقطة انطلاق وليس مسرداً معتمداً نهائياً.
4. **قرّر نموذج العمل.** إن كان الموقع تجارياً فاضبط `MARSAD_SITE_COMMERCIAL=true`، فتنزل مصادر CC BY-NC مثل TNSR إلى الملخص فقط.
5. **أضف مفتاح Claude API** في `ANTHROPIC_API_KEY`. لم يُختبر الاتصال الحي بالنموذج في بيئة البناء لعدم وجود مفتاح فيها.
6. **للبحث بالمعنى** أضف مفتاح Voyage AI في `MARSAD_VOYAGE_API_KEY`، ثم املأ المتجهات للمواد المنشورة سابقاً:

   ```bash
   marsad embed
   ```

   لم يُختبر الاتصال الحي بـ Voyage في بيئة البناء. بعد أول تشغيل جرّب عتبة التشابه `MARSAD_SEMANTIC_MIN_SIMILARITY` على عينة من عمليات البحث.
7. **للنشرة البريدية** أضف إعدادات SMTP من أي مزوّد. بدونها يظهر نموذج الاشتراك معطلاً برسالة واضحة.
8. **المصادر غير الإنجليزية** مسجلة غير مفعّلة: المعهد الفرنسي للعلاقات الدولية، والمجلس الروسي للشؤون الدولية،
   ومعهد دراسات الأمن القومي الإسرائيلي بالعبرية، والمعهد الصيني للدراسات الدولية. قبل تفعيل أي منها:
   راجع مسرد لغته مع مترجم متخصص (في `engine/marsad/data/glossary_multilingual.yaml`)، وتحقق من خلاصته وحقوقه.
9. **مفاتيح الواجهة البرمجية** يصدرها المدير من «مفاتيح الواجهة» في غرفة التحرير، ويظهر المفتاح مرة واحدة فقط.
10. **مجلة التاريخ العسكري:** افحص صفحتها ثم فعّلها:

   ```bash
   marsad sources check jmh
   ```

   ```bash
   marsad sources set jmh --active
   ```

## التشغيل المحلي للتطوير

المتطلبات: Python 3.12 أو أحدث، Node 22، PostgreSQL 16.

```bash
cd engine
python -m venv .venv && .venv/bin/pip install -e ".[dev]"
```

```bash
createdb marsad && createdb marsad_test
```

```bash
.venv/bin/marsad db-upgrade && .venv/bin/marsad seed
```

لتجربة الموقع دون مفتاح ودون إنترنت، حمّل ثلاث مواد عرض وهمية من مصدرين وهميين واضحي التسمية:

```bash
MARSAD_LLM_BACKEND=fake .venv/bin/marsad demo
```

```bash
.venv/bin/marsad create-user editor@example.org "اسم المحرر" --role admin
```

```bash
MARSAD_LLM_BACKEND=fake .venv/bin/marsad api
```

وفي نافذة أخرى:

```bash
cd web && npm install && ENGINE_URL=http://127.0.0.1:8000 npm run dev
```

العامل الذي يرصد ويعالج (يحتاج مفتاح API وإنترنت):

```bash
.venv/bin/marsad worker
```

لرؤية الرسائل البريدية محلياً دون خادم بريد، يكتب وضع البريد التجريبي كل رسالة ملفاً في مجلد:

```bash
MARSAD_MAIL_BACKEND=fake MARSAD_FAKE_MAIL_DIR=./outbox .venv/bin/marsad api
```

## النشر على خادم

```bash
cp .env.example .env
```

عدّل `.env` (النطاق، كلمة مرور قاعدة البيانات، مفتاح API)، ثم:

```bash
docker compose up -d --build
```

```bash
docker compose run --rm api marsad create-user editor@example.org "اسم المحرر" --role admin
```

يحصل Caddy على شهادة HTTPS تلقائياً. تُفتح الواجهة العامة `/v1` للمؤسسات، وتبقى واجهة المحرك الداخلية `/api` خاصة. تُحفظ نسخة احتياطية يومية في `backups/`.
للاسترجاع:

```bash
docker compose exec -T db pg_restore -U marsad -d marsad --clean < backups/marsad-YYYY-MM-DDTHHMM.dump
```

## العمل اليومي للمحرر

- **صف المراجعة:** المواد الأهم أولاً. المادة المبنية على ملخص منشور تحمل إشارة واضحة، ولا تُترجم نصوصها.
- **مقال بوصول مفتوح:** من صفحة المادة، سجّل الترخيص ودليله، فيُعاد تنزيل النص الكامل وترجمته.
- **النشرة:** كل أسبوع تظهر مسودة في «النشرة». احذف ما لا تريد، وعدّل المقدمة، ثم اضغط «أرسل النشرة». يرسلها العامل على دفعات.
- **الإزالة:** «إزالة من الموقع» تخفي المادة فوراً عند أي طلب من صاحب الحقوق، وتختفي معها من الملفات الموضوعية ومن الواجهة البرمجية.
- **الملفات الموضوعية:** أنشئ ملفاً، وأضف المواد من الاقتراحات، واطلب مقدمة مقترحة ثم راجعها واحفظها قبل النشر.
- **التقرير الشهري:** في أول كل شهر تظهر مسودة قراءة للشهر السابق في «الاتجاهات». قارنها بالأرقام المعروضة تحتها، ثم احفظها وانشرها.

## قرارات تختلف عن الخطة الأصلية

- **عدّاد حدود الطلبات في قاعدة البيانات** لا في ذاكرة العملية، فيبقى الحد صحيحاً مهما تعددت نسخ المحرك.
- **الاتجاهات تُحسب من تاريخ النشر الأصلي** لكل مادة رُصدت وصُنّفت، لا من تاريخ نشرها في المرصد، حتى لا يشوّه تأخر المراجعة الأرقام.
- **حسابات القرّاء بلا كلمات مرور**، فلا نخزن كلمات مرور للقرّاء أصلاً.

- **لا Redis ولا Celery في المرحلة الأولى.** صف المهام هو قاعدة البيانات نفسها (`FOR UPDATE SKIP LOCKED`)،
  وهذا يكفي لعشرات المواد يومياً ويقلل الخدمات التي تحتاج صيانة. يمكن تشغيل أكثر من عامل بأمان.
- **CSS مباشر بدل Tailwind**، لأن الموقع صغير ويعتمد على متغيرات تصميم قليلة.
- **المتجهات تُحسب في العامل بعد النشر** لا لحظة النشر، فلا يتعطل نشر مادة إذا تعطّل مزوّد المتجهات.
- **رابط إلغاء الاشتراك داخل الرسالة يفتح صفحة فيها زر**، حتى لا تلغي برامج فحص الروابط في البريد الاشتراكات خطأً.
  أما ترويسة الإلغاء بنقرة واحدة فتعمل بطلب POST كما يقتضي المعيار.
